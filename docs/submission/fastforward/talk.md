Hello, I am Alberto Jaspe from KAUST, and this is X3D Copilot.

[0 s, still life] Everyone has tried asking a language model for a 3D scene. It writes something that looks right, and then the browser shows a blank screen. The model invents field names, misplaces nodes, and never sees its own output.

X3D Copilot fixes that. It is a complete X3D 4.0 editor that runs in your browser: a live view, the source, drag-and-drop objects, import and export. And it has an AI co-author.

[10 s, prompt] You just type what you want. "A snowman at night." [18 s, snowman] The AI does not write the file blind. It reads the X3D specification, edits the scene through tools, and then the standard checks the result: the official schema, a set of semantic rules, and the 3D runtime. Any error goes straight back to the AI, and it must repair it before it answers you. Then it looks at the render to confirm.

[32 s, shadows and click] You keep talking. Add moon shadows. Make the hat jump when I click it. Every step is validated, every step renders.

[54 s, solar system and gizmo] And it is still a real editor: animated scenes, direct manipulation of objects, and the source always in sync.

[82 s, materials] Physically based materials, shadows, everything X3D 4.0 offers.

[95 s, repair] Hand it a scene with eleven errors, and it repairs all of them in one request.

Why does this matter? Generative 3D is only useful if the result is a standard file that everyone can load. Here, every scene that leaves the tool is valid X3D 4.0, by construction.

It is open source, it runs today with Gemini or Claude using your own key, and the link is on the slide. Scan it, type a sentence, and get a valid scene. Thank you.
